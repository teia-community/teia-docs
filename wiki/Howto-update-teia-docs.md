## This is a wiki

Wiki's are great way to write some quick docs, get feedback and collaborate with others.

This is a [GitHub Wiki](https://docs.github.com/en/communities/documenting-your-project-with-wikis/about-wikis) but we are not using this wiki to describe documentation about this particular "Teia Docs" repo, and how to use it, which is what this feature of GitHub is meant for, we are using it to draft documentation for the [Teia DAO](https://teia.art/dao) itself!

Some of us are putting documentation into the Teia UI itself.  And some of us thought it would be nice to create a documentation site using [Docusaurus](https://docusaurus.io/) because sometimes it's nice to have an upstream provider, kind of like Tezos itself, Docusaurus is an open source tool with an amazing community behind it, so we are really just experimenting with how our more stable documentation looks in it.

If you have created a wiki page, and you think it's in a place where you want to publish it on the [Teia Docs](docs.teia.org) site, check this page here:

- https://docs.teia.art/dev-howtos/howto-update-teia-docs

If no one has updated the page in a while, this is a good candidate to publish there, if the page is under review and heavy drafting, then wait awhile.
